# Random Password Generator

A beginner-friendly Python command-line application that generates random passwords based on user choices.

## Features

- Lets the user choose the password length
- Enforces a minimum password length of 8 characters
- Allows uppercase letters, lowercase letters, numbers, and symbols
- Requires at least two character types for stronger passwords
- Makes sure each selected character type is included
- Validates invalid input
- Lets the user generate multiple passwords without restarting the program

## Technologies Used

- Python
- `random`
- `string`

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run this command:

```powershell
python password_generator.py
